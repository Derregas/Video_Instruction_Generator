# Инструкция по установке (Windows GPU)

1. **Создайте виртуальное окружение:**
   ```powershell
   python -m venv .venv
   .\.venv\Scripts\Activate.ps1
   ```

2. **Установите PyTorch с поддержкой CUDA 12.1:**
   Это необходимо для работы Whisper на видеокарте.
   ```powershell
   pip install torch --index-url https://download.pytorch.org/whl/cu121
   ```
   *Также может потребоваться установка CUDA toolkit, если он не установится вместе с torch.*

3. **Установите остальные зависимости:**
   ```powershell
   pip install -r requirements.txt
   ```

4. **Установите FFmpeg:**
   FFmpeg необходим для извлечения аудио из видео.
   - Скачайте сборку с https://ffmpeg.org/download.html
   - Распакуйте и добавьте папку `bin` в PATH системы или установите его в папке `/tools` в корне проекта.

5. **Установите Ollama и модель:**
   - Скачайте Ollama: https://ollama.com/download/windows
   - Установите модель:
     ```powershell
     ollama pull gemma4:e4b
     ```

6. **Установите poppler**
   - Скачайте Poppler: https://github.com/oschwartz10612/poppler-windows/releases?ysclid=mpy8o1yyiy882157089
   - Распакуйте его в папке `/tools` в корень проекта
   *Рекомендуется использовать версию 25.12.0 от 4 декабря 2025г.*

7. **Установите Tessercst-OCR**
   - Скачайте Tesseract: https://github.com/UB-Mannheim/tesseract/wiki
   - Установите в папку `/tools` в корень проекта

8. **Скопируйте шаблон конфигурации:**
   В корне проекта должен быть файл `.env.example`.
   ```powershell
   copy .env.example .env
   ```

9. **Настройте переменные окружения:**
   Откройте `.env` и проверьте основные параметры:
   - `LLM_MODEL` — модель, например `gemma4:e4b`.
   - `WHISPER_MODEL` — размер модели Whisper (`base` по умолчанию).
   - `WHISPER_DEVICE` — `cpu` или `cuda`.
   - `USE_LAST_DATA` и `LAST_DATA_FILE_NAME` — опции сохранения/повтора последних данных.

10. **Создайте администратора:**
   Перед первым запуском обязательно создайте администратора, если `users.db` ещё нет.
   ```powershell
   python create_admin.py
   ```
   Этот скрипт создаёт первого пользователя с правами администратора.

## Запуск приложения

### Вариант 1: через `start.bat`

Просто запустите `start.bat` из корня проекта. Он:
- создаст виртуальное окружение, если его нет;
- активирует его;
- установит зависимости;
- проверит наличие `users.db`;
- запустит `python app.py`.

### Вариант 2: вручную

```powershell
.\.venv\Scripts\Activate.ps1
python app.py
```

После старта приложение будет доступно по адресу:

```text
http://127.0.0.1:5000
```

## Использование

1. Откройте браузер и зайдите на `http://127.0.0.1:5000`.
2. Авторизуйтесь с учётной записью администратора или зарегистрируйтесь, если в системе уже есть права на регистрацию.
3. Перейдите в раздел задач:
   - `/task` — создание новой задачи;
   - `/` — список всех задач;
   - `/auth/users` — управление пользователями (для админов).
4. На странице создания задачи загрузите видео и, при необходимости, дополнительные документы.
5. Нажмите кнопку `Начать обработку`.
6. Интерфейс автоматически опрашивает сервер и отображает состояние обработки.
7. Когда задача завершится, на странице появится сгенерированная инструкция.
8. Вы можете редактировать инструкцию прямо в браузере и сохранять изменения.
9. Инструкцию можно экспортировать в `pdf` или `docx` из меню экспорта.

## Примечания

- При использовании CUDA убедитесь, что соответствующие драйверы и библиотеки CUDA установлены.
- Если приложение запускается не на Windows, используйте соответствующий способ активации виртуального окружения и установки FFmpeg.
- Логи пишутся в файл `generator.log`.
